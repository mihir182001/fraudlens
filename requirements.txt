# requirements.txt, FraudLens Week 1 through Week 5. Only what the code in
# this project actually imports, added as each week is built and each
# import is traced for real. Later weeks (scorecardpy, modAL, PySpark,
# FastAPI, Streamlit, ...) will add their own dependencies here as those
# weeks are built, the same discipline SearchLens's requirements-*.txt
# split followed after that project's own requirements.txt drift bug.
#
# torch is pinned to its CPU-only build via the extra index below, not
# plain PyPI. Plain `pip install torch` resolves a build bundling full
# NVIDIA CUDA libraries (confirmed directly: a plain install pulled in
# over 6 GB of nvidia-* packages), which is pure dead weight on a machine
# with no GPU, exactly the kind of thing that filled your C: drive back in
# Week 1. The +cpu version suffix forces pip to resolve specifically the
# CPU-only build, which has no CUDA dependencies at all.
--extra-index-url https://download.pytorch.org/whl/cpu
